# Stack Tecnológico

## Lenguaje
- **Go**: 1.25.0

## Dependencias Principales

### UI / GUI
- **gotk4/pkg v0.3.1** (`github.com/diamondburned/gotk4/pkg`): Bindings GTK4 para Go
- **msgbox v0.3.0** (`github.com/Tobotobo/msgbox`): Diálogos de mensaje

### PDF
- **gofpdf v1.16.2** (`github.com/jung-kurt/gofpdf`): Generación de PDFs

## Dependencias Indirectas
- **weak** (`github.com/KarpelesLab/weak`): Utilidades débiles
- **govaluate** (`github.com/Knetic/govaluate.v3`): Evaluación de expresiones
- **golang.org/x/sys**, **golang.org/x/sync**: Utilidades del sistema

## Notas
- Widgets personalizados: El proyecto usa GTK4 para crear/modificar widgets de interfaz
- Compatible con Windows
